# Магазин электроники и товаров для сада

## О проекте

Проект представляет собой систему управления товарами интернет-магазина, реализованную на Python с использованием объектно-ориентированного программирования.

## Функциональность
Базовые классы
Product (Товар)
Атрибуты: название, описание, цена, количество

## Архитектурные улучшения

### Абстрактный базовый класс
- Реализован абстрактный класс `BaseProduct`, определяющий общий интерфейс для всех продуктов
- Содержит абстрактные методы: `__init__`, `__str__`, `__add__`, property `price`

### Класс-миксин для логирования
- Реализован миксин `LoggingMixin` для логирования создания объектов
- При создании объекта выводит в консоль информацию о классе и параметрах
- Используется множественное наследование

### Цепочка наследования

## Методы:

- __add__ - сложение товаров (сумма произведений цены на количество)

- price - property с валидацией (цена должна быть положительной)

- new_product - класс-метод для создания товара из словаря

## Category (Категория)
Атрибуты: название, описание, список товаров

## Методы:

add_product - добавление товара в категорию с проверкой типа

products - property для строкового представления товаров

Статистика: подсчет общего количества категорий и товаров

## Специализированные классы-наследники
Smartphone (Смартфон)
Наследует от Product и добавляет:

Производительность (efficiency)

Модель (model)

Объем памяти (memory)

Цвет (color)

LawnGrass (Газонная трава)
Наследует от Product и добавляет:

Страна-производитель (country)

Срок прорастания (germination_period)

Цвет (color)

## Новые возможности в этой версии
1. Ограничение сложения товаров
Реализована проверка типов при сложении товаров

Можно складывать только товары одного класса

При попытке сложить разные классы выбрасывается TypeError

### Пример:

smartphone1 + smartphone2  # ✅ Работает
smartphone1 + lawn_grass   # ❌ TypeError

2. Защита от добавления некорректных объектов
Метод add_product проверяет, что добавляемый объект является экземпляром Product или его наследников

Используется функция isinstance() для проверки типа

3. Итерация по товарам категории
Реализован класс CategoryIterator для итерации по товарам категории

Поддержка протокола итерации Python

## Установка и запуск
Клонируйте репозиторий:

git clone <repository-url>
Установите зависимости:

pip install pytest pytest-cov
Запустите основные скрипты:

python 16.1_main.py
Запустите тесты:

pytest test_classes.py -v
Проверьте покрытие тестами:


pytest --cov=src --cov-report=html
